Shift Left Insights – User Documentation
📌 Overview
Shift Left Insights is a Forge-powered app for Jira that helps teams and management visualize how bugs are distributed across different project phases. It provides a stacked area chart to support data-driven decisions.

🚀 Features
Select a Jira Project and associated Custom Fields

Click Submit to generate a stacked area chart

Visually identify which phases consume more effort or lag behind

Enables teams and leaders to spot bottlenecks and improve delivery

🧭 How to Use
Create a Dashboard and Add the Shift Left Insights gadget

Select Project and Fields
Choose the Jira project and relevant custom fields (e.g., Phase, Effort).

Click Submit
The app will generate a stacked area chart based on the selected data.

Analyze the Chart
Use the visual representation to see how work or issues are distributed across phases.

🎯 Use Cases
Identify bottlenecks in the delivery pipeline

Visualize trends in time/effort allocation

🛠 Requirements
You must have access to Jira Cloud.

Custom fields should be properly configured for your project.
